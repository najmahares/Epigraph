 The Collection

A curated archive of 100 quotes from books, films, among others.


 What It Does

A single-page quote collection with a split-screen layout. Left side: sticky category navigation with scroll progress. Right side: quotes that fade in as you scroll.gold accents.



 Built With

- HTML
- CSS
- JavaScript


 How to Run

1. Clone the repo
2. Open `index.html` in any browser
